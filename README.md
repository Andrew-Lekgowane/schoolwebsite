## 🚀 Quick Start

### Option 1: Open Directly
Simply open `index.html` in your web browser:
```bash
open index.html
```

### Option 2: Use a Local Server (Recommended)
For the best experience, use a local development server:

**Using Python:**
```bash
python -m http.server 8000
```

**Using Node.js (http-server):**
```bash
npx http-server
```

**Using PHP:**
```bash
php -S localhost:8000
```

Then visit: `http://localhost:8000`

## 🔧 Customization Guide

### Change School Name
Edit in `index.html`:
```html
<span>Excellence Academy</span>
```

### Update Colors
Modify CSS variables in `styles.css`:
```css
:root {
    --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    /* Add your custom colors here */
}
```

### Add More Sections
Follow the existing section structure in `index.html`:
```html
<section class="your-section" id="your-id">
    <div class="container">
        <!-- Your content -->
    </div>
</section>
```

### Modify Statistics
Update the `data-target` attributes in the hero stats:
```html
<div class="stat-number" data-target="1500">0</div>
```

## 💡 Key Features Explained

The numbers in the hero section animate from 0 to their target value when scrolled into view.
